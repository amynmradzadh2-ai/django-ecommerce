# Django E-Commerce

A simple e-commerce web application built with Django.

## Features

- User Authentication
- Product Categories
- Product Management
- Django Admin Panel
- SQLite Database

## Technologies

- Python
- Django
- HTML
- CSS
- SQLite

## Installation

```bash
git clone https://github.com/amynmradzadh2-ai/django-ecommerce.git
cd django-ecommerce
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
